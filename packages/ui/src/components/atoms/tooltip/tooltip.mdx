# Tooltip

Informational popup displayed on hover or focus.

<Primary />

## Installation

```bash
pnpm dlx shadcn@latest add https://ui.vllnt.com/r/tooltip.json
```

## Import

```tsx
import {
  Tooltip,
  TooltipContent,
  TooltipProvider,
  TooltipTrigger,
} from '@vllnt/ui'
```

## Usage

```tsx
<Tooltip>Hover me</Tooltip>
```

## Dismissal

`TooltipContent` takes `onEscapeKeyDown`, `onPointerDownOutside`, `onInteractOutside` and `onFocusOutside`; call `event.preventDefault()` in one to keep the tooltip open. A closed tooltip stays in the page, hidden, so `forceMount` is accepted and has no effect.
