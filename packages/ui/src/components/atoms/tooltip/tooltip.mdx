# Tooltip

Informational popup displayed on hover or focus.

<Primary />

## Installation

```bash
pnpm dlx shadcn@latest add https://ui.vllnt.com/r/tooltip.json
```

## Import

```tsx
import {
  Tooltip,
  TooltipArrow,
  TooltipContent,
  TooltipProvider,
  TooltipTrigger,
} from '@vllnt/ui'
```

## Usage

```tsx
<Tooltip>Hover me</Tooltip>
```

## Arrow

Put a `TooltipArrow` inside `TooltipContent` to point at the trigger. It follows the side the tooltip lands on, including after a flip, and is hidden from assistive technology. The content stops clipping its children once it holds an arrow. It is filled with `bg-popover`, which does not match the default glass content; style it with `className`, for example a background that matches your content.

## Close delay

`closeDelay` on `Tooltip` is how many milliseconds the tooltip stays open after the pointer leaves the trigger and the tooltip. It defaults to 0.

<Canvas of={Stories.CloseDelay} sourceState="shown" />

## Touch

Touch screens have no hover, so a plain tooltip never opens there. `toggleable` on `Tooltip` makes a press on the trigger (finger, mouse or keyboard) open and close it; an outside press or Escape closes it too. With a mouse, hovering opens it first, so the first press keeps it open and the next closes it. Use it on an info button that exists to show the tip.
