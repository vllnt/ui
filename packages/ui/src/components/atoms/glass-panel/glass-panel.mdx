# GlassPanel

Frosted-glass surface for floating chrome that sits on top of the canvas — dock panels, hovering toolbars, transient overlays. Translucent background with a soft border, optional rounded radius. Pure presentation; the host slots whatever content belongs above the canvas.

<Primary />

## Installation

```bash
pnpm dlx shadcn@latest add https://ui.vllnt.com/r/glass-panel.json
```

## Import

```tsx
import { GlassPanel } from '@vllnt/ui'
```

## Usage

```tsx
<GlassPanel className="absolute right-4 top-4 p-3">
  <ObjectInspector …/>
</GlassPanel>
```

## Notes

- The panel uses the default glass tint. Add the `vllnt-glass-dense` class for body text, muted text or a control border, which need the denser tint to stay AA.
- `material="solid"` draws an opaque panel. The panel also turns solid on its own under `prefers-reduced-transparency`, `prefers-contrast: more`, `forced-colors: active`, without `backdrop-filter` support, and under `html[data-glass="off"]`.
- Keep few frosted layers on screen at once; the budget in `DESIGN.md` allows 5.
