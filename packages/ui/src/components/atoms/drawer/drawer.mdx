# Drawer

Slide-out panel anchored to the screen edge.

<Primary />

## Installation

```bash
pnpm dlx shadcn@latest add https://ui.vllnt.com/r/drawer.json
```

## Options

- `overlay`: `"scrim"` (default) dims the page, `"none"` draws no veil. The panel stays modal either way.
- `onEscapeKeyDown`, `onPointerDownOutside`, `onInteractOutside`, `onFocusOutside`: call `event.preventDefault()` to keep the drawer open.
- `forceMount`: keeps the panel in the page while closed.
