# Kbd

Keyboard key indicator for displaying shortcuts. Pass a single child for one key, or use the `shortcut` prop with a `+`-delimited string for platform-aware multi-key combos. The `platform` prop forces Mac or Windows labels, and the `bracket` variant drops the key cap for `[K]`-style keys.

<Primary />

## Installation

```bash
pnpm dlx shadcn@latest add https://ui.vllnt.com/r/kbd.json
```

## Import

```tsx
import { Kbd } from '@vllnt/ui'
```

## Usage

```tsx
<Kbd>K</Kbd>

{/* Composed manually */}
Press <Kbd>Ctrl</Kbd> + <Kbd>K</Kbd>

{/* Auto-expanded via the shortcut prop */}
<Kbd shortcut="mod+k" />
```

## Variants

| Value | Default | Look |
| ----- | ------- | ---- |
| `default` | Yes | Boxed key cap with a hairline border and shadow |
| `bracket` | - | No key cap; the key sits between decorative `[` `]` brackets |

The `variant` prop is the Penpot `Style` axis (`style` is already the HTML inline-style attribute). Brackets are hidden from assistive tech, so a shortcut keeps the same accessible name in both variants.

## Platform

| Value | Default | Effect on `shortcut` |
| ----- | ------- | -------------------- |
| `auto` | Yes | Follows the browser user agent |
| `mac` | - | Always Mac labels |
| `win` | - | Always Windows / Linux labels |

`platform` only changes how a `shortcut` is expanded. Explicit `children` render as given.

On Mac, `mod` and `meta` render a vector command icon (not the `⌘` text glyph) with the accessible name `Command`. Because a shortcut is exposed as one image, the wrapper label reads `Command + K`.

## Shortcut prop

The `shortcut` prop expands a `+`-delimited token list. Special tokens:

| Token | Mac | Other |
| ----- | --- | ----- |
| `mod` | command icon | `Ctrl` |
| `meta` | command icon | `Win` |
| `ctrl` | `⌃` | `Ctrl` |
| `alt` | `⌥` | `Alt` |
| `shift` | `⇧` | `Shift` |
| `enter` / `return` | `↵` | `↵` |
| `escape` | `Esc` | `Esc` |
| `tab` | `⇥` | `⇥` |
| `space` | `Space` | `Space` |
| `backspace` | `⌫` | `⌫` |
| `delete` | `⌦` | `⌦` |
| `arrowup` / `arrowdown` / `arrowleft` / `arrowright` | `↑` / `↓` / `←` / `→` | same |
