# SegmentedControl

A single-choice segmented selector built on the existing toggle-group primitive for compact view, filter, and mode switching.

<Primary />

## Installation

```bash
pnpm dlx shadcn@latest add https://ui.vllnt.com/r/segmented-control.json
```

## Import

```tsx
import { SegmentedControl, SegmentedControlItem } from '@vllnt/ui'
```

## Usage

```tsx
<SegmentedControl aria-label="Project view" defaultValue="board">
  <SegmentedControlItem value="board">Board</SegmentedControlItem>
  <SegmentedControlItem value="list">List</SegmentedControlItem>
  <SegmentedControlItem value="timeline">Timeline</SegmentedControlItem>
</SegmentedControl>
```

## Fit and hairline

`fit` hugs the content: the root takes `w-auto` and the items `flex-none`, instead of filling the row. `variant="hairline"` replaces the filled track with a transparent one and a 1 px border. The border is the input colour, which inside glass is the AA-checked `glass-input`, so place a hairline control on the dense glass tint (`vllnt-glass vllnt-glass-dense`). The default stays `variant="filled"`, full width.

## Accessibility

- The control is one tab stop and lands on the selected segment.
- Arrow keys, Home and End move focus between segments, skip disabled ones and wrap at the ends. Space or Enter selects the focused segment.
- The selection transition stops under `prefers-reduced-motion`.
