# Button

Interactive button with multiple variants and sizes.

<Primary />

## Installation

```bash
pnpm dlx shadcn@latest add https://ui.vllnt.com/r/button.json
```

## Import

```tsx
import { Button } from '@vllnt/ui'
```

## Usage

```tsx
<Button>Click me</Button>
```

`unstyled` adds no classes: the button keeps its behaviour (`asChild`, `disabled`, ref, every native attribute) and draws only what `className` gives it. `size` has no effect with it. It also drops the focus ring and the disabled look, so give `className` its own `focus-visible:` and `disabled:` styles.

## UnstyledButton: without tailwind-merge

`UnstyledButton` (also from `@vllnt/ui/button`) is a `button` with no classes of its own. It joins `className` with `cx`, so its module never imports `tailwind-merge` and adds none to a client bundle. `Button` merges classes with `cn`, which brings `tailwind-merge` (about 7 kB gzip). `type` defaults to `"button"`. It has no `asChild`; use `Button variant="unstyled"` for that. Give `className` its own `focus-visible:` and `disabled:` styles.

```tsx
import { UnstyledButton } from "@vllnt/ui/button";

<UnstyledButton className="rounded-sm px-3 focus-visible:ring-2">A</UnstyledButton>
```
