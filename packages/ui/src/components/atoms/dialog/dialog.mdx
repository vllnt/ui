# Dialog

Modal dialog overlay for focused content and actions.

<Primary />

## Installation

```bash
pnpm dlx shadcn@latest add https://ui.vllnt.com/r/dialog.json
```

## Import

```tsx

  Dialog,
  DialogClose,
  DialogContent,
  DialogDescription,
  DialogFooter,
  DialogHeader,

  DialogPortal,
```

## Options

- `overlay`: `"scrim"` (default) dims the page, `"none"` draws no veil. The panel stays modal either way.
- `closeButton`: pass `false` to drop the corner close button when the content has its own `DialogClose`.
- `labels.close`: accessible name of the corner close button.
- `onEscapeKeyDown`, `onPointerDownOutside`, `onInteractOutside`, `onFocusOutside`: call `event.preventDefault()` to keep the dialog open.
- `forceMount`: keeps the panel in the page while closed.
