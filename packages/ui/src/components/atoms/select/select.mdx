# Select

Dropdown select input for choosing from a list of options.

<Primary />

## Installation

```bash
pnpm dlx shadcn@latest add https://ui.vllnt.com/r/select.json
```

## Import

```tsx
import {
  Select,
  SelectContent,
  SelectGroup,
  SelectItem,
  SelectLabel,
  SelectScrollDownButton,
  SelectScrollUpButton,
  SelectSeparator,
  SelectTrigger,
  SelectValue,
} from '@vllnt/ui'
```

## Usage

```tsx
<Select>Select content</Select>
```

## Invalid state

Set `aria-invalid="true"` on `SelectTrigger`. The trigger takes the destructive border; the text keeps its colour, so show the error message as text in the foreground colour next to the field.

<Canvas of={Stories.Invalid} sourceState="shown" />

## Accessibility

- Keyboard: Enter or Down Arrow opens the menu. Arrows, Home, End and typing move between items and skip disabled ones. Enter selects, Escape closes without a change, and focus returns to the trigger.
- The open and close animation stops under `prefers-reduced-motion`.
