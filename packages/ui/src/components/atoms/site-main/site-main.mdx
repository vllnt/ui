# SiteMain

The page landmark: `<main id="main" tabIndex={-1}>`. It is the target of the skip link in `SiteFrame`. A page has one.

<Primary />

## Installation

Add it with the shadcn CLI from the component registry: the registry page of this component lists the command (`r/site-main.json`).

## Import

```tsx
import { SiteMain } from '@vllnt/ui'
```

## Usage

```tsx
<SiteMain className="flex-1">{children}</SiteMain>
```

### In a flex column

## Accessibility

- One `main` per page. Do not render the footer inside it.
- `id="main"` is what the skip link points at. `tabIndex={-1}` lets the jump move focus into the page without adding a tab stop.
