# Toggle Group

Group of toggle buttons for single or multiple selection.

<Primary />

## Installation

```bash
pnpm dlx shadcn@latest add https://ui.vllnt.com/r/toggle-group.json
```

## Import

```tsx
import { ToggleGroup, ToggleGroupItem } from '@vllnt/ui'
```

## Usage

```tsx
<ToggleGroup>
  <ToggleGroup.displayName />
</ToggleGroup>
```

## Unstyled

`variant="unstyled"` on the group drops its layout classes and every item's classes; each part draws only its `className`. The group keeps its roles, values and arrow-key focus. Set it on one `ToggleGroupItem` to unstyle that item alone, in a group that sets no `variant` (the group's `variant` wins over the item's).
