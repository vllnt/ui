# Toggle Group

Group of toggle buttons for single or multiple selection.

<Primary />

## Installation

```bash
pnpm dlx shadcn@latest add https://ui.vllnt.com/r/toggle-group.json
```

## Import

```tsx
import { ToggleGroup, ToggleGroupItem } from '@vllnt/ui'
```

## Usage

```tsx
<ToggleGroup>
  <ToggleGroup.displayName />
</ToggleGroup>
```

## UnstyledToggleGroup: without tailwind-merge or class-variance-authority

`UnstyledToggleGroup` and `UnstyledToggleGroupItem` (also from `@vllnt/ui/toggle-group`) keep the Radix behaviour of `ToggleGroup`: roving focus with one tab stop, arrow keys, Home and End, radio items when `type="single"` and pressed buttons when `type="multiple"`, and `disabled`. They add no classes, and `className` reaches the element as given, so their module imports neither `tailwind-merge` nor `class-variance-authority`. Style the states with `data-[state=on]:`, `focus-visible:` and `disabled:` classes, and give the group an `aria-label`. Import it from a `"use client"` module: Next turns each client module that a server component imports into a client reference, so a server-component import of `@vllnt/ui/toggle-group` also brings `ToggleGroup`, `tailwind-merge` and `class-variance-authority`.

```tsx
import { UnstyledToggleGroup, UnstyledToggleGroupItem } from "@vllnt/ui/toggle-group";

<UnstyledToggleGroup aria-label="View" className="inline-flex gap-1" type="single">
  <UnstyledToggleGroupItem className="px-3 data-[state=on]:bg-accent" value="grid">Grid</UnstyledToggleGroupItem>
  <UnstyledToggleGroupItem className="px-3 data-[state=on]:bg-accent" value="list">List</UnstyledToggleGroupItem>
</UnstyledToggleGroup>
```
