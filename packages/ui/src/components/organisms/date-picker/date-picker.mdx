# DatePicker

Calendar-popover date input — text field with a calendar grid for picking a single date. Pure presentation; the host owns the date value and can bound it with `calendarProps`. The calendar loads when the popover first opens, and a blank placeholder of the same size holds its place until it arrives.

Pair with \`Calendar\` (the underlying month grid) for embedded calendar UI without the popover.

<Primary />

## Installation

```bash
pnpm dlx shadcn@latest add https://ui.vllnt.com/r/date-picker.json
```

## Import

```tsx
import { DatePicker } from '@vllnt/ui'
```

## Usage

```tsx
<DatePicker
  value={date}
  onValueChange={setDate}
  calendarProps={{ fromDate: today }}
/>
```

## Notes

- The calendar takes `locale` and `weekStartsOn` through `calendarProps`.
- Focus lands on the selected day (else today) when the popover opens, and arrow keys, Page Up and Page Down move through the dates.
- Pair with \`Form\` and \`Label\` for accessible form composition.
