Shows which permissions each subject holds, as a table or as one list entry per subject. Each cell reads granted, denied or inherited, with a glyph and a word, so the state never rests on colour alone. With `onChange`, granted and denied cells become buttons that ask for the opposite state; inherited cells never change. Pick the `grid` or `list` mode and keep the value on your side. Part of the data family in VLLNT UI, it ships as a
machine-readable registry entry — copy the source directly into your app with
the shadcn CLI and own it, no runtime dependency on a component library.
