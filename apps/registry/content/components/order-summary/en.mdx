Order summary with priced rows, a total, an optional promo code form and a checkout button. It is pure presentation: you format every value and own the cart and the promo state, and the component reports `onApply` and `onCheckout`. The promo form has `idle`, `applying` and `error` states, the checkout button has a loading state, and a `desktop` or `phone` layout changes the density. Part of the billing family in VLLNT UI, it ships as a
machine-readable registry entry — copy the source directly into your app with
the shadcn CLI and own it, no runtime dependency on a component library.
