Settings section with an optional heading and description above a list of rows. Each row, built with `SettingsListItem`, holds a label, an optional description, a leading icon or avatar, a right-side value and at most one trailing control: a `Switch`, a link, a button or a chevron. The root is a labelled `<section>` in an `inset-grouped` or `plain` style. Part of the form family in VLLNT UI, it ships as a
machine-readable registry entry — copy the source directly into your app with
the shadcn CLI and own it, no runtime dependency on a component library.
